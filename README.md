# Air Quality Index (AQI) Prediction Model

## Overview
This project predicts the Air Quality Index (AQI) using Machine Learning techniques based on environmental and pollutant parameters. The model analyzes air quality data and provides AQI predictions to help monitor pollution levels and support environmental decision-making.

## Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature selection and engineering
- Machine Learning model training
- AQI prediction and evaluation
- Performance visualization using graphs and charts

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
